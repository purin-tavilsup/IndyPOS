# StoreHub Production Configuration Guide

This document explains each configuration property in `appsettings.json`.

---

## ConnectionStrings

### `storehub-db`

**What:** PostgreSQL connection string for the StoreHub database.

**Format:**
```
Host=<ip>;Port=<port>;Database=<db>;Username=<user>;Password=<pass>
```

**How to get:**
- `Host`: IP address of PostgreSQL server (use `127.0.0.1` for local)
- `Port`: PostgreSQL port (default: `5432`)
- `Database`: Created by `install-config.ps1` (default: `indypos_storehub`)
- `Username`: Created by `install-config.ps1` (default: `indypos_app`)
- `Password`: The password you provided to `install-config.ps1`

**Used by:** Entity Framework Core to connect to the database for all data operations (products, invoices, users, etc.)

**Example:**
```json
"storehub-db": "Host=127.0.0.1;Port=5432;Database=indypos_storehub;Username=indypos_app;Password=MySecurePass123"
```

## LocalToken

JWT (JSON Web Token) settings for authentication between WinForms and StoreHub.

### `SecretKey`

**What:** Secret key used to sign JWT tokens. Must be at least 32 characters.

**How to get:**
- Auto-generated by the installer (64 bytes, Base64 encoded), then DPAPI-protected inside `appsettings.json` (no separate key file)
- Or generate manually: `[Convert]::ToBase64String((1..64 | ForEach-Object { Get-Random -Max 256 }))`

**Used by:**
- StoreHub signs tokens when users log in
- StoreHub validates tokens on every API request

**Security:** Keep this secret! Anyone with this key can forge authentication tokens.

### `Issuer`

**What:** Identifier of who issued the token.

**How to get:** Use default `IndyPOS.StoreHub` (no need to change).

**Used by:** Token validation - tokens must have matching issuer.

### `Audience`

**What:** Intended recipient of the token.

**How to get:** Use default `IndyPOS.POS` (no need to change).

**Used by:** Token validation - tokens must have matching audience.

### `ExpiryHours`

**What:** How long tokens remain valid (in hours).

**How to get:** Default is `12` hours (covers a long shift). Adjust based on your needs.

**Used by:** Token generation - sets the `exp` claim in JWT.

**Example:**
```json
"LocalToken": {
  "SecretKey": "dGhpcyBpcyBhIHZlcnkgbG9uZyBzZWNyZXQga2V5IGZvciBqd3Q=",
  "Issuer": "IndyPOS.StoreHub",
  "Audience": "IndyPOS.POS",
  "ExpiryHours": 12
}
```

## StoreIdentity

### `StoreId`

**What:** Unique identifier for this store location.

**How to get:**
- Assign a unique ID for each store (e.g., `STORE-001`, `STORE-002`)
- Must be consistent across all systems (StoreHub, CloudApi, MigrationTool)

**Used by:**
- Prefixed to all entity IDs (e.g., `STORE-001_INV_00001`)
- Cloud sync to identify which store data belongs to
- Multi-store reporting

**Example:**
```json
"StoreIdentity": {
  "StoreId": "STORE-001"
}
```

## CloudApi

Settings for syncing data to the central cloud API (optional, for multi-store setups).

### `BaseUrl`

**What:** URL of the CloudApi service.

**How to get:**
- Leave empty `""` if not using cloud sync
- Set to your CloudApi URL when ready (e.g., `https://cloud.indypos.app`)

**Used by:** SyncWorker to push outbox events to cloud.

### `ClientId`

**What:** OAuth2 client identifier for this store.

**How to get:**
- Generated when registering this store in CloudApi
- Each store gets a unique client ID

**Used by:** OAuth2 client credentials flow for authentication.

### `ClientSecret`

**What:** OAuth2 client secret (like a password).

**How to get:**
- Generated when registering this store in CloudApi
- Keep secret! Don't share or commit to source control

**Used by:** OAuth2 client credentials flow for authentication.

### `Scopes`

**What:** OAuth2 scopes (permissions) requested.

**How to get:** Use default `sync.write master.read` (no need to change).

**Used by:** Determines what operations the store can perform on CloudApi.

**Example (cloud sync enabled):**
```json
"CloudApi": {
  "BaseUrl": "https://cloud.indypos.app",
  "ClientId": "store-001-client",
  "ClientSecret": "super-secret-value",
  "Scopes": "sync.write master.read"
}
```

**Example (cloud sync disabled):**
```json
"CloudApi": {
  "BaseUrl": "",
  "ClientId": "",
  "ClientSecret": "",
  "Scopes": "sync.write master.read"
}
```

## SyncWorker

Background service that syncs local data to cloud.

### `Enabled`

**What:** Whether to run the cloud sync background worker.

**How to get:**
- Set to `false` for local-only deployment (no cloud)
- Set to `true` when CloudApi is configured and ready

**Used by:** SyncWorker checks this on startup - exits immediately if disabled.

**Example:**
```json
"SyncWorker": {
  "Enabled": false
}
```

## Logging

ASP.NET Core logging configuration.

### `LogLevel`

**What:** Minimum severity level to log for each category.

**Levels (least to most severe):**
- `Trace` - Very detailed (debugging)
- `Debug` - Debugging information
- `Information` - General flow
- `Warning` - Unexpected but handled
- `Error` - Failures
- `Critical` - System failures

**How to get:**
- Production: Use `Warning` (less noise, important events only)
- Debugging: Use `Information` or `Debug`

**Categories:**
- `Default`: All loggers not otherwise specified
- `Microsoft.AspNetCore`: ASP.NET Core framework logs
- `Microsoft.EntityFrameworkCore`: Database query logs

**Example:**
```json
"Logging": {
  "LogLevel": {
    "Default": "Warning",
    "Microsoft.AspNetCore": "Warning",
    "Microsoft.EntityFrameworkCore": "Warning"
  }
}
```

## Complete Example

```json
{
  "ConnectionStrings": {
    "storehub-db": "Host=127.0.0.1;Port=5432;Database=indypos_storehub;Username=indypos_app;Password=MySecurePass123"
  },
  "LocalToken": {
    "SecretKey": "dGhpcyBpcyBhIHZlcnkgbG9uZyBzZWNyZXQga2V5IGZvciBqd3Q=",
    "Issuer": "IndyPOS.StoreHub",
    "Audience": "IndyPOS.POS",
    "ExpiryHours": 12
  },
  "StoreIdentity": {
    "StoreId": "STORE-001"
  },
  "CloudApi": {
    "BaseUrl": "",
    "ClientId": "",
    "ClientSecret": "",
    "Scopes": "sync.write master.read"
  },
  "SyncWorker": {
    "Enabled": false
  },
  "Logging": {
    "LogLevel": {
      "Default": "Warning",
      "Microsoft.AspNetCore": "Warning",
      "Microsoft.EntityFrameworkCore": "Warning"
    }
  }
}
```

## Security Checklist

- [ ] `SecretKey` is unique and not committed to source control
- [ ] `Password` in connection string is strong and not shared
- [ ] `ClientSecret` (if using cloud) is kept confidential
- [ ] Config file has restricted permissions (Administrators only)
- [ ] Backups of config are encrypted or secured
