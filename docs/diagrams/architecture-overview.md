## Offline Resilience

```
                    ┌─────────────────────────────────────────┐
                    │             NORMAL OPERATION            │
                    │                                         │
    ┌───────────┐   │   ┌───────────┐       ┌───────────┐   │
    │  ONLINE   │───┼──>│Processing │──────>│  Syncing  │   │
    │           │   │   │           │<──────│           │   │
    └─────┬─────┘   │   └───────────┘       └───────────┘   │
          │         │                                        │
          │ Network │                                        │
          │  Lost   └────────────────────────────────────────┘
          │
          ▼
    ┌───────────┐   ┌─────────────────────────────────────────┐
    │  OFFLINE  │   │          OFFLINE OPERATION              │
    │           │───│                                         │
    └─────┬─────┘   │   ┌───────────┐       ┌───────────┐   │
          │         │   │Local Only │──────>│  Queued   │   │
          │ Network │   │           │<──────│ (Outbox)  │   │
          │Restored │   └───────────┘       └───────────┘   │
          │         │                                        │
          └─────────│   Sales continue normally.             │
                    │   Events queue in Outbox.              │
                    │   Sync resumes when online.            │
                    └─────────────────────────────────────────┘
```
