## Daily Cash Flow Reconciliation

```
┌─────────────────────────────────────┐     ┌─────────────────────────────────────┐
│         EXPECTED CASH               │     │          ACTUAL CASH                │
├─────────────────────────────────────┤     ├─────────────────────────────────────┤
│                                     │     │                                     │
│  (+) Sales Total (excl. PayLater)   │     │  ฿1000 notes  x _____ = _______    │
│  (+) Received PayLater Payments     │     │  ฿500 notes   x _____ = _______    │
│  (+) Changes (customer returns)     │     │  ฿100 notes   x _____ = _______    │
│  (-) Money Transfer                 │     │  ฿50 notes    x _____ = _______    │
│  (-) Welfare Card                   │     │  ฿20 notes    x _____ = _______    │
│  (-) Payouts                        │     │  ฿10 coins    x _____ = _______    │
│                                     │     │  ฿5 coins     x _____ = _______    │
├─────────────────────────────────────┤     │  ฿2 coins     x _____ = _______    │
│  = EXPECTED TOTAL: ___________      │     │  ฿1 coins     x _____ = _______    │
│                                     │     ├─────────────────────────────────────┤
└─────────────────────────────────────┘     │  = ACTUAL TOTAL: ___________       │
                                            └─────────────────────────────────────┘

                    ┌─────────────────────────────────────┐
                    │           DIFFERENCE                │
                    │   Actual - Expected = _________     │
                    ├─────────────────────────────────────┤
                    │  = 0    →  ✓ Balanced              │
                    │  ≠ 0    →  ⚠ Investigate           │
                    └─────────────────────────────────────┘
```

## Cloud Sync Flow

```
 StoreHub          Outbox Table        SyncWorker          Cloud API
     │                  │                   │                   │
     │ INSERT event     │                   │                   │
     │ (same TX as sale)│                   │                   │
     ├─────────────────>│                   │                   │
     │                  │                   │                   │
     │                  │    (Every 30s)    │                   │
     │                  │                   │                   │
     │                  │ SELECT WHERE      │                   │
     │                  │ sent = false      │                   │
     │                  │<──────────────────┤                   │
     │                  │                   │                   │
     │                  │     Events found  │                   │
     │                  ├──────────────────>│                   │
     │                  │                   │                   │
     │                  │                   │ POST /sync/events │
     │                  │                   ├──────────────────>│
     │                  │                   │                   │
     │                  │                   │     200 OK        │
     │                  │                   │<──────────────────┤
     │                  │                   │                   │
     │                  │ UPDATE sent=true  │                   │
     │                  │<──────────────────┤                   │
     │                  │                   │                   │
     │                  │                   │                   │
     │                  │    (On failure)   │                   │
     │                  │                   │                   │
     │                  │                   │ POST /sync/events │
     │                  │                   ├──────────────────>│
     │                  │                   │                   │
     │                  │                   │   5xx / timeout   │
     │                  │                   │<──────────────────┤
     │                  │                   │                   │
     │                  │                   │ Exponential       │
     │                  │                   │ backoff & retry   │
     │                  │                   │                   │
```
